# C# Core Learning – Practice & Concepts

This repository is my personal learning journey with **C#** and **.NET**.  
It's purely for understanding and mastering core concepts through small, focused classes and examples. No big application — just clean code to revisit fundamentals.

Built with **.NET 8.0** and Visual Studio / dotnet CLI.

## ✨ What's Inside
Organized by learning sessions / classes:

- **2ndClass** → **13thClass** (including special ones like `11thClassOop`, `12thClass_Async`, `13thClass_LinQ`)
- **10_Practise** → Extra hands-on practice problems and mini-exercises

Each folder usually contains:
- `Program.cs` with examples and explanations (often with comments)
- Related class files demonstrating one main concept

## 📚 Topics Covered So Far
| Class/Folder          | Main Topic(s)                          | Key Concepts Practiced                  |
|-----------------------|----------------------------------------|------------------------------------------|
| 2ndClass – 10thClass  | Basics, variables, control flow, methods, arrays, strings | Input/output, loops, conditionals, functions |
| 11thClassOop          | Object-Oriented Programming            | Classes, objects, constructors, encapsulation, inheritance, polymorphism |
| 12thClass_Async       | Asynchronous Programming               | async/await, Task, threading basics     |
| 13thClass_LinQ        | Language Integrated Query (LINQ)       | Query syntax, method syntax, filtering, projection, grouping |
| 10_Practise           | Mixed practice                         | Problem-solving, refactoring, combining concepts |

(Will keep adding more advanced topics like generics, delegates, events, collections, exceptions, file I/O, etc.)
